# Ambient Clock

A full-screen ambient clock for a TV web browser. Slow color themes crossfade every few minutes and the clock drifts a little each minute.

Live page: https://padamop.github.io/ambient-clock/

- Press OK on the remote (or click) to go full screen.
- Left and right arrow keys switch themes, if the browser passes them through.
- Everything is in `index.html`: no build step and no external requests.
